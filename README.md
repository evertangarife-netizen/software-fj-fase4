# Sistema Integral de Gestión de Clientes, Servicios y Reservas – Software FJ

Proyecto correspondiente a la **Fase 4 – Prácticas simuladas** del curso **Programación (Código 213023)** de la Universidad Nacional Abierta y a Distancia (UNAD).

## Características del sistema
- **Arquitectura POO sin base de datos:** gestión en memoria mediante objetos y listas internas.
- **Pilares aplicados:** clases abstractas (`Entidad`, `Servicio`), encapsulación, herencia, polimorfismo y sobrecarga simulada en `calcular_costo()`.
- **Manejo avanzado de excepciones:** excepciones personalizadas, bloques `try/except`, `try/except/else`, `try/except/finally` y encadenamiento (`raise ... from ...`).
- **Auditoría:** registro automático de eventos y errores en `software_fj.log`.
- **Validación:** simulación de 12 operaciones completas (exitosas y fallidas) sin interrupciones.

## Ejecución
python main.py
